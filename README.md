<h1>📊 Multi Calculator Web App</h1>
<h1>📌 Introduction</h1>
This project is a Multi Calculator Web Application built using basic web technologies. It includes multiple useful calculators in a single interface, making it easy for users to perform different types of calculations quickly and efficiently.<br>
The purpose of this project is to demonstrate fundamental front-end development concepts such as forms, user input handling, and JavaScript-based calculations.<br>
<h1>🎯 Objectives</h1>
<li>To build a simple and user-friendly calculator system</li>
<li>To practice HTML form handling and JavaScript logic</li>
<li>To provide multiple utilities in one web application</li>
<li>To improve problem-solving and coding skills</li>
<h1>🚀 Features</h1>
This application includes the following calculators:<br>
<h3>1️⃣ Percentage Calculator</h3>
Calculates percentage based on:<br>
<li>Total Marks</li>
<li>Obtained Marks</li>
<h3>2️⃣ BMI Calculator</h3>
Calculates Body Mass Index using:<br>
<li>Weight</li>
<li>Height</li>
<h3>3️⃣ BMR Calculator</h3>
Calculates Basal Metabolic Rate based on:<br>
<li>Height</li>
<li>Weight</li>
<li>Age</li>
<h3>4️⃣ Ushr Calculator</h3>
<li>Calculates Ushr based on total agricultural production</li><br>
<h3>5️⃣ Zakat Calculator</h3>
<li>Calculates Zakat based on zakatable amount</li><br>
<h1>🛠️ Technologies Used</h1>
<li>HTML5 – Structure of the web page</li>
<li>JavaScript – Logic and calculations</li>
<li>(Optional) CSS – Styling (can be added for better UI)</li>
<h1>📂 Project Structure</h1>

<h1>⚙️ How It Works</h1>
<li>User enters required values in input fields</li>
<li>Clicks the Submit button</li>
<li>JavaScript function is triggered (e.g., getBMI(), getZakat())</li>
<li>Result is calculated and displayed</li>
